## How to Run

### 1. Clone the repo
```
git clone git@github.com:M-Alsuleibi/python-task-1.git
cd python-task-1
```
### 2. Create and activate virtual environment
```
python3 -m venv venv
source venv/bin/activate        # Linux/macOS
venv\Scripts\activate           # Windows
```
### 3. Run the program
```
python main.py
```
